# ⭐ Atrapa la estrella

Actividad de iniciación con **Python + Pygame Zero** para el módulo de Programación de 1.º de DAW (FP).

El cuaderno [`atrapa_la_estrella_solucion_explicada.ipynb`](atrapa_la_estrella_solucion_explicada.ipynb) explica la solución fase a fase. Ya está ejecutado y se puede abrir directamente en Google Colab:

[![Abrir en Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/maximofernandezriera/atrapa-la-estrella/blob/main/atrapa_la_estrella_solucion_explicada.ipynb)

Como Colab no puede abrir ventanas, el cuaderno simula la pantalla de Pygame Zero. Al final se puede descargar `estrella.py` para jugar en local:

```
pip install pgzero
python estrella.py
```
